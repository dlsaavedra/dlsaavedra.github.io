## Public GitHub repositories

All public repositories are available on [my GitHub profile](https://github.com/dlsaavedra?tab=repositories).

- [rcens](https://github.com/dlsaavedra/rcens) — R package for generating censored samples.
- [gamex_summer_school_gan](https://github.com/dlsaavedra/gamex_summer_school_gan) — fork of a practical session on generative modelling for extremes and risk.
- [dlsaavedra.github.io](https://github.com/dlsaavedra/dlsaavedra.github.io) — source of this website.
- [Examples_Martingale_posterior_distributions](https://github.com/dlsaavedra/Examples_Martingale_posterior_distributions) — examples using martingale posterior distributions.
- [DDPGMM_HT_SelectVariables](https://github.com/dlsaavedra/DDPGMM_HT_SelectVariables) — code for Bayesian model selection with heavy-tailed data.
- [gamex_summer_school_cascades](https://github.com/dlsaavedra/gamex_summer_school_cascades) — fork of a practical session on cascading extremes.
- [gamex_summer_school_neural](https://github.com/dlsaavedra/gamex_summer_school_neural) — fork of a practical session on neural generative models.
- [Detector_GDXray](https://github.com/dlsaavedra/Detector_GDXray) — detectors for dangerous objects in X-ray images.
- [Prueba_Web_Site](https://github.com/dlsaavedra/Prueba_Web_Site).
- [Hormiga_Centralidad_Grafo](https://github.com/dlsaavedra/Hormiga_Centralidad_Grafo) — ant-inspired graph centrality heuristic.
