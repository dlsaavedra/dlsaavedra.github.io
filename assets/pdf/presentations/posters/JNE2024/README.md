# Nueva presentación, póster o asistencia

1. Copia esta carpeta dentro de `conferences`, `seminars`, `attendance` o `posters` y cambia el nombre de la copia (por ejemplo, `2026-congreso-de-estadistica`).
2. Edita `info.yml` con el nombre del evento, el título de la presentación, póster o participación, y el nombre exacto del archivo cuando corresponda. Añade `date: "AAAA-MM-DD"` con la fecha del evento para ordenar las entradas de más nueva a más antigua. Si no conoces la fecha exacta, incluye el año en el nombre de la carpeta.
3. Añade el PDF a esa misma carpeta. Si usas una imagen JPG, PNG o WebP, reemplaza `pdf:` por `file:` en `info.yml`. Para `attendance`, el archivo es opcional: elimina la línea `pdf` si no tienes uno.
4. Sube la carpeta a GitHub. La entrada aparecerá al terminar la publicación de la web.

Cada carpeta representa una sola presentación, póster o asistencia.
