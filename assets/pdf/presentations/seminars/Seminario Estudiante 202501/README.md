# Nueva presentación o póster

1. Copia esta carpeta dentro de `conferences`, `seminars`, `invited-talks` o `posters` y cambia el nombre de la copia (por ejemplo, `2026-congreso-de-estadistica`).
2. Edita `info.yml` con el nombre del evento, el título de la presentación o póster y el nombre exacto del PDF.
3. Añade el PDF a esa misma carpeta.
4. Sube la carpeta a GitHub. La entrada aparecerá al terminar la publicación de la web.

Cada carpeta representa una sola presentación o póster.
